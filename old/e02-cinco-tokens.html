Ejercicio E2

Cinco tokens, cinco disparos

Generás cinco tokens de tipos distintos, los disparás a propósito y comparás qué metadata trajo cada uno. Los tokens no son intercambiables y acá se ve por qué.

Guardado
Objetivo

Entender, con los callbacks en la mano, qué te dice cada tipo de token y qué no. La elección del tipo es una decisión de diseño que condiciona todo el E3: dónde lo plantás depende de qué información necesitás que te devuelva. Los tokens se generan en canarytokens.org y avisan por mail: podés usar el tuyo o uno temporal, por ejemplo de yopmail.com.

1 · Generá los cinco

Cinco tipos, no cinco tokens del mismo tipo. En la descripción de cada uno poné algo que te sirva después: «E3 · documento del repositorio» es útil dentro de tres horas, «prueba» no. Anotá también la URL de administración de cada token: la vas a necesitar en el E13 para ver el historial de disparos.

2 · Disparalos

Terminal
# DNS — mirá qué IP aparece del otro lado
dig +short a1b2c3d4e5.canarytokens.com

# credenciales AWS — el token registra la llamada, no el login
AWS_ACCESS_KEY_ID=AKIA... AWS_SECRET_ACCESS_KEY=... \
  aws s3 ls --region us-east-1

# web bug — abrilo desde el navegador, no con curl:
#   curl no manda user-agent de browser y el token trae menos
# DNS — mirá qué IP aparece del otro lado
Resolve-DnsName a1b2c3d4e5.canarytokens.com -Type A
#   si no tenés el módulo DNS:  nslookup a1b2c3d4e5.canarytokens.com

# credenciales AWS — el token registra la llamada, no el login
#   PowerShell no acepta VAR=valor delante del comando: van aparte
$env:AWS_ACCESS_KEY_ID     = "AKIA..."
$env:AWS_SECRET_ACCESS_KEY = "..."
aws s3 ls --region us-east-1

# web bug — abrilo desde el navegador, no con curl:
#   curl no manda user-agent de browser y el token trae menos

El .docx y el QR se disparan a mano: abrí el documento con Word y escaneá el QR con el celular. Fijate que el QR va a traer la red móvil, no la del aula — es otro punto de observación.

3 · Leé los cinco callbacks

Lo que hay que notar
  • El DNS te da el resolver, no al adversario. Si usa 8.8.8.8, tenés a Google.
  • El web bug te da user-agent e IP, y los pierde detrás de un proxy corporativo.
  • Las credenciales AWS te dicen qué llamada intentó y desde dónde: es el único que te cuenta la intención.
  • El documento dispara desde la máquina de quien lo abre, que puede no ser la que lo descargó.
