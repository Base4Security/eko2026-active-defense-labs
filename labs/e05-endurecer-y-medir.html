Ejercicio E5

Endurecé el honeypot y medí el delta

Tomás la lista de delatores del E1 y los arreglás uno por uno. Pero antes y después corrés el mismo fingerprint, con los mismos comandos, para que el resultado sea un número y no una impresión.

Guardado
Objetivo

Arreglar lo que se puede arreglar con configuración, descubrir qué es inherente a la herramienta, y salir con una tabla antes/después donde cada fila diga si el delator sigue ahí.

Dónde se corre esto

Todos los comandos de esta ficha salen desde la carpeta mi-lab/ del repositorio, salvo que se aclare lo contrario:

cd eko2026-active-defense-labs/mi-lab

Si no sabés dónde quedó, está en la preparación del programa.

2 · Arreglá

Cuatro frentes. El cuarto es el que casi nadie hace y el que más delata.

El banner

El version string de Cowrie sale en cowrie.cfg. No inventes uno raro: poné el que tendría una máquina real de EkoFinance, coherente con lo que dice el resto del inventario. Un banner exótico delata tanto como el de fábrica.

La identidad

Hostname, dominio, y userdb.txt con usuarios que podrían existir en esta organización. root/123456 abriendo la puerta es la firma de un honeypot sin tocar.

El filesystem

Poblá honeyfs/ con un sistema que tenga historia: home de usuario con archivos, algo en /opt, logs viejos, un .bash_history plausible. Un /home vacío dice «acá no vivió nadie».

Las fechas

Este es el difícil. Un filesystem donde todo se modificó el mismo día —el día que lo levantaste— se cae ante un ls -la. Repartí las fechas de modificación en meses, y que sean coherentes: el log tiene que ser más nuevo que el binario que lo escribe.
Fechas
# repartí las fechas de modificación hacia atrás
touch -d "2026-02-14 09:22" honeyfs/opt/conciliacion/README
touch -d "2026-06-03 17:41" honeyfs/var/log/app.log

# verificá que la historia cierre
ls -la --time-style=long-iso honeyfs/opt/conciliacion/

3 · Fingerprint después

Los mismos comandos. Si cambiás el comando, no estás midiendo.

Terminal
docker compose restart cowrie

nmap -sV -p 2222 --script ssh2-enum-algos,banner localhost > fingerprint/despues.txt
ssh -v root@localhost -p 2222 2>&1 | grep -i "remote software" >> fingerprint/despues.txt

diff fingerprint/antes.txt fingerprint/despues.txt

Lo que no se arregla con configuración

Algunos delatores son de la herramienta, no del despliegue: la forma en que Cowrie responde a ciertos comandos, los timings, el conjunto de binarios que simula. Anotalos igual y marcalos como Sigue: saber qué no podés esconder es parte del diseño.

Y es el argumento del carril A: cuando el disfraz de un sistema falso no aguanta, la alternativa es esconder el engaño adentro de un sistema real, que no necesita disfraz porque no es un disfraz.

Entregable · se usa en E14

La tabla antes/después con el estado de cada delator, y la lista de los que no se pueden arreglar con configuración. El E14 va a poner a prueba lo que quedó.
