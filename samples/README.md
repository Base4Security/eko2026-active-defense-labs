# samples/ — carnada en la raíz

Montá esta carpeta en **`/`**. El [`index.html`](index.html) lista cada recurso
con el link real (`/backoffice.html`, `/env.txt`, …). Las piezas ya vienen con
contenido de ejemplo (keys, hosts, paneles) para ver cómo se ve la carnada.
No son tokens vivos: si las plantás en el lab, reemplazalas con las tuyas de
[canarytokens.org](https://canarytokens.org/).
